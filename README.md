# 🐠 BettaHub

## Professional Aquarium Management System

BettaHub, akvaryum hobisini profesyonel seviyeye taşıyan kapsamlı bir yönetim platformudur.

## Amaç

Balık üreticileri, hobiciler ve işletmeler için;

- Balık Yönetimi
- Akvaryum Yönetimi
- Sağlık Takibi
- Üretim Takibi
- Yavru Takibi
- Raporlama
- Yapay Zekâ Destekli Hastalık Analizi
- Çoklu Dil Desteği
- Bulut Senkronizasyonu

gibi özellikleri tek bir platformda sunmayı amaçlar.
